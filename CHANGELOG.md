# Changelog

All notable changes to cull-audit are documented here. This file follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow
[Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-10-03

The first public release, covering the M1 and M2 work:

- versioned judgment contracts and the `validate` CLI;
- deterministic flip, stability, and repeat-read metrics;
- auditable known, estimated, and unknown cost accounting;
- an opt-in Gemini reference runner with environment-only API key handling;
- a keyless synthetic demo and a licensed open-photo demo manifest;
- a local-first privacy posture with no default telemetry or network activity.
